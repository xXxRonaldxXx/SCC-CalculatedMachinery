# SCC: Calculated Machinery

An add-on for [SCC - Super Cool Calculator](https://github.com/xXxRonaldxXx/SuperCoolCalculator) for Minecraft 1.21.1 and 26.1.2 (NeoForge). This repository is the bug tracker for it. The mod itself is published on CurseForge.

[Report a bug or suggest a feature](../../issues/new/choose)

Requires SCC 1.5.3 or newer. The add-on does nothing without it.

## What the add-on does

It adds 13 basic machines in the SCC tiers (Basic to Singularity): Smelting, Crushing, Pressing, Alloying and Sawing Calculators, a Cobble Calculator, Fluid Pump, Condensing Calculator, Star Collector and Combustion Calculator, and Enchanting, Recycling and Charging Calculators. They take power from the SCC network, can pull inputs from storage and push results back, and the processing machines can be used by SCC autocrafting. Higher tiers are faster and run more in parallel, but never give more output per ore than the recipe.

## Before you report

- The SCC manual in game has a chapter for the add-on.
- Problems with SCC itself (network, storage, autocrafting) go to the [SCC tracker](https://github.com/xXxRonaldxXx/SuperCoolCalculator/issues).

## What to put in a bug report

- Add-on version, SCC version, Minecraft/NeoForge version and the modpack if you use one.
- `logs/scc.log` and `logs/latest.log` (or the crash report if the game crashed).
- What you did, what you expected and what happened. Screenshots help.
